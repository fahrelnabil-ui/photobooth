# 📸 BerkahBooth — Korean Aesthetic Web Photobooth

Aplikasi web photobooth interaktif modern bergaya bilik foto Korea (seperti Life4Cuts / Haru Film / Photoism) dengan filter estetik real-time, multi-layout strip & grid, 8 tema bingkai kaya ornamen, stiker interaktif, dan ekspor kolase kualitas HD.

---

## ✨ Fitur Unggulan

- **Live Camera & Audio System**: Dukungan kamera web real-time dengan efek suara jepretan, hitung mundur, dan cermin (*mirror camera*).
- **Multi-Layout Template**:
  - *4-Cut Korean Strip* (Vertikal 4 Pose)
  - *3-Cut Classic Strip* (Vertikal 3 Pose)
  - *2x2 Modern Grid* (Kotak Studio 4 Pose)
  - *Single Aesthetic Polaroid* (1 Foto Besar)
- **8 Tema Desain Bingkai Unik**:
  - 🚨 *Penjara / Mugshot*
  - 📚 *Perpustakaan Vintage*
  - 🎞️ *Film 35mm Negatif*
  - 📰 *Koran Jadul (The Daily Chronicles)*
  - 👾 *Y2K Cyber Arcade*
  - 🌸 *Sakura Pastel Floral*
  - 🎨 *Washi Tape Scrapbook*
  - 🏢 *Minimalis Studio White*
- **Filter Warna Real-time**: Normal, Korean Soft, Noir B&W, Warm Retro, Analog Film, Cyberpunk, Seoul Cafe, Vintage Fade.
- **Stiker Lucu Interaktif**: Tempel dan geser (*drag & drop*) stiker emoji langsung di atas pratinjau kolase.
- **Ekspor HD**: Unduh kolase resolusi tinggi (PNG/JPEG) atau langsung cetak foto (*Print*).

---

## 🚀 Menjalankan Secara Lokal

1. Buka terminal di folder proyek:
   ```bash
   python -m http.server 5173
   ```
2. Buka browser di:
   `http://localhost:5173`

*(Atau di Windows, cukup klik 2x file `jalankan.bat`)*

---

## 🛠️ Teknologi

- HTML5 Canvas & MediaDevices API
- Web Audio API (Synthesizer Audio)
- Vanilla JavaScript (ES Module)
- Tailwind CSS & Custom Light Glassmorphism
- Lucide Icons
